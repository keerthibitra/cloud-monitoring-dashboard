# Cloud Monitoring Dashboard

## Project Overview

Cloud Monitoring Dashboard is a web-based application that simulates monitoring cloud infrastructure metrics.

The dashboard displays:

* CPU Usage
* Memory Usage
* Disk Usage
* Network Traffic

The metrics are refreshed automatically to simulate real-time cloud monitoring.

## Features

* Real-time metric simulation
* User-friendly dashboard
* Responsive design
* Cloud monitoring concepts

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Cloud Concepts Covered

* Resource Monitoring
* Performance Metrics
* Infrastructure Health
* Dashboard Visualization
